## 🔧 구현 내용

### 색상 인식 기반 주행 (`color_follower.py`)
- **파란색 라인 추종**: 카메라 영상에서 파란색 라인을 검출하고 P제어로 라인 중앙을 따라 주행
- **노란색 교차로 감지**: 바닥의 노란색 마커를 감지하면 교차로로 판단
- **Visual Edge Alignment**: 노란색 타일이 화면 하단을 지나 사라지는 순간을 기준으로 회전 타이밍을 결정 (하드코딩 거리 없이 시각 정보만 활용)
- **녹색 목적지 도킹**: 목적지의 녹색 마커를 인식하면 감속·정렬 후 정지
- **경로 설정**: YAML 파일에 목적지별 교차로 회전 방향(L/R/S)을 정의하여 경로 지정

---

## 로직

1. **화면 하단 30%만 감시** — 멀리 있는 노란색 타일 오인 방지
2. **노란색이 화면 맨 아래를 통과 → 사라지는 순간** 회전 시작
3. **Cooldown 거리 0.3m** — 같은 교차로 중복 인식 방지
